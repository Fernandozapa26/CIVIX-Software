# ADR-0001 — Decisiones técnicas iniciales
Estado: parcialmente confirmado, pendiente de revisión por el equipo.

## Confirmado
- Angular + TypeScript (frontend)
- ASP.NET Core + C# (backend)
- SQL Server (base de datos)
- Git/GitHub, monorepositorio
- MVP: Usuarios/Seguridad, Obras, Materiales, Cotizaciones, Avances

## Pendiente
- Versiones concretas de Angular, Node.js, .NET y SQL Server
- ASP.NET Core Identity u otro mecanismo de autenticación
- Roles/permisos finales y reglas de acceso por obra
- Uso de EF Core y estrategia de migraciones
- Relación obligatoria u opcional entre cotización y obra
- Tratamiento de impuestos, descuentos y PDF
- Porcentaje de avance y estados de las obras
- Hospedaje, CORS y estrategia de despliegue
