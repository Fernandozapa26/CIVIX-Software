# Convenciones de colaboración
- Rama principal: `main`. No realizar cambios directos sin revisión.
- Ramas por historia: `feature/obras-crud`, `feature/usuarios-login`, `fix/cotizaciones-total`.
- Cada PR debe incluir requisito (RF-xxx), descripción, evidencia y pruebas.
- No subir secretos, contraseñas, tokens, bases de datos ni carpetas `bin/`, `obj/` o `node_modules/`.
- Validar el esquema y los contratos API con los demás integrantes.
